# Architecture decision records

A decision record says why a design was chosen over the alternatives that
were weighed at the time, so the reasoning outlives the working plan that
argued it out (plans are not kept in the repository; `AGENTS.md`
§ "Documentation & Instructions Maintenance").

Each entry is one file, `NNNN-<short-name>.md`, numbered in the order it
was written, with the sections `## Status`, `## Context`, `## Options`,
`## Decision` and `## Consequences`. An entry is not rewritten when the
decision changes: a new entry supersedes it, and the old one's status says
so and links the new one.
